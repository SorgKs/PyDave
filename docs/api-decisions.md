# API объектов — зафиксированные решения

Сессия уточнения API (ветка `game-engine-architecture-86710`).  
Связанные документы: `concept_refactor.md`, `engine/README.md`, `docs/api-open-questions.md`.

---

## 1. Модель объекта

**Решение:** объект — `dict`, логика — функции в `anims/`.

- Доступ к полям: `obj['x']`, `obj['vx']`, …
- Вызовы: `anims.behave(...)`, `anims.transform(...)`
- Не классы с методами (`obj.behave()`, `obj.x`)

---

## 2. Фабрика и владение структурой

**Решение:** единственная фабрика — `anims.create_object`.

- Реестр типов в `anims/` знает hitbox, якорь, слой, `init` / `behave` / `transform`
- `engine.objects` — только хелперы (`get_hitbox_rect`, `add_collision`, offsets), **без** своей фабрики
- Каноническая структура dict живёт в `anims`

---

## 3. `behave`

**Сигнатура (по смыслу):**

```text
behave(obj, keys, triggers, map)
```

| Аргумент     | Назначение                                      |
|--------------|-------------------------------------------------|
| `obj`        | объект-словарь                                  |
| `keys`       | состояние кнопок (нажато / удерживается)        |
| `triggers`   | триггеры уровня                                 |
| `map`        | карта                                           |

**Права на запись:**

- **Нельзя** менять `obj['x']` / `obj['y']`
- **Можно** менять направление (`face`), скорость (`vx` / `vy`), прыжок (обычно через `vy`)

Координаты после `behave` пишет только физика.

---

## 4. `transform`

**Сигнатура:**

```text
transform(obj)
```

**Когда вызывать:** каждый кадр, для каждого объекта.

**Входы (на объекте):**

- `obj['collisions']` — список коллизий после физики
- `obj['state']` — текущее состояние

**Поведение:**

- Читает коллизии и `state`
- Может менять смещение спрайта → пишет в `obj` (`sprite_offset_*` и аналоги)
- Меняет свойства объекта: жизни, очки, патроны (`obj['hp']`, `obj['score']`, `obj['ammo']` и т.п. — поля **конкретного** объекта, не глобальный `game_state`)
- После обработки **удаляет / очищает** `obj['collisions']`

**Спрайт:**

- Отдельная `get_sprite` **не нужна**
- Спрайт выдаёт `transform` (детали возврата vs поле в `obj` — см. открытые вопросы)

---

## 5. Игровой цикл (целевой)

```text
для каждого obj:
    behave(obj, keys, triggers, map)

physics.update_physics(objects)   # пишет pos, заполняет collisions

для каждого obj:
    transform(obj)                # каждый кадр; чистит collisions

render(...)                       # читает спрайт/оффсет с obj (или возврат transform)
```

---

## 6. Краткая шпаргалка контрактов

| Функция     | Меняет pos? | Меняет vel/face? | Спрайт / оффсет | HP / score / ammo | collisions        |
|-------------|-------------|------------------|-----------------|-------------------|-------------------|
| `behave`    | нет         | да               | нет             | нет               | не трогает        |
| `physics`   | да          | да (разрешение)  | нет             | нет               | заполняет         |
| `transform` | нет*        | не зафиксировано | да (в `obj`)    | да (на `obj`)     | читает и очищает  |

\* Явно не обсуждали правку координат в `transform`; по текущим решениям позиция — зона физики.
