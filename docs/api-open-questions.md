# API объектов — открытые вопросы

Вопросы, которые ещё не закрыты в сессии уточнения API.  
Закрытые ответы переносить в `docs/api-decisions.md` и вычёркивать отсюда.

---

## Q1. Как `transform` отдаёт спрайт рендеру? — закрыт

**Решение:** карта спрайтов через `sprites_map` типов + тайлы в `assets`; `transform` возвращает имя ключа.  
См. `api-decisions.md` §4, §9.

---

## Q2. Формат `keys` для `behave` — закрыт

**Решение:** токены `действие+модификатор`: `l+` нажато, `l=` удерживается (и аналогично для остальных действий).  
См. §3.

---

## Q3. Формат `map` и `triggers` — закрыт

**Решение:** `map` = `surface_grid`; триггеры пишутся в obj при срабатывании.  
См. §3, §5.

---

## Q4. Vel / face в `transform` — закрыт

**Решение:** координаты — физика; `transform` — визуал и внутренние поля; `vx`/`vy` для отскока не трогает.  
См. §4, §6.

---

## Q5. Поля dict — закрыт

**Решение:** общее ядро у всех; остальное в индивидуальном `init`.  
См. §7.

---

## Q6. Типы с карты — закрыт

**Решение:** парсер сразу `create_object` + `init`.  
См. §8.

---

## Q7. Гравитация / трение — закрыт

**Решение:** флаги на obj; расчёт только в `physics`.  
См. §10.

---

## Q8. `init` / offsets / anchor — закрыт

- **Q8.1** `compute_offsets` один раз в `create_object` после `init` (§11)
- **Q8.2** `init(obj, params) -> None` (§12)
- **Q8.3** канон `anchor_type`: `'ground'` / `'center'` (§13)

---

## Пробелы для реализации (вне исходного Q1–Q8)

Закрыто:
- формат `keys` (`l+` / `l=` …) — §3
- единицы: тайлы; `map` = surface_grid — §3, §7
- триггеры: имя + индивидуальные доп. данные — §3
- физические `collisions`: свой набор на вид; часто достаточно факта — §3
- knockback: второй проход `physics` — §4, §5, §6
- `layer`: одно int-число, не биты — §7, §14
- `sprites_map`: dict ключ→имя файла; доступ по ключу — §4, §9
- кадры от якоря (`ground`=bottom-center, `center`=центр); hitbox offsets один раз — §11

**Открытых пробелов из списка больше нет.** Можно сверять готовность к реализации или добавлять новые вопросы.
